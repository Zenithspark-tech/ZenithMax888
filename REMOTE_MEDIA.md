# Remote starter media

The 156 starter video records no longer bundle MP4 files inside this repository. Each starter record points to a remote HTTPS MP4 URL, so the project stays small and the browser streams the media when it is needed.

The default remote library contains public video sample URLs used in web/video demonstrations, including Big Buck Bunny, Elephants Dream, Sintel and Tears of Steel, plus Google's GTV sample clips. The app keeps the normal HTML5 `<video>` audio track in the source file; the watch player exposes volume controls and Shorts have a sound toggle.

These URLs are intended for demo/staging use. Before a production launch, replace the starter library with media you have permission to stream and add the appropriate attribution/licensing information. Pexels is another option for production-safe stock video integration through its API, subject to its current terms and attribution requirements.
